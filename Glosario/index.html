Glosario de Bases de Datos NoSQL y Modelado

Agregación de datos (Aggregation)

Proceso mediante el cual se agrupan o transforman datos almacenados en una base de datos NoSQL para obtener información resumida o estructurada. Es común en bases documentales como MongoDB mediante pipelines de agregación.

Colección (Collection)

Conjunto de documentos dentro de una base de datos documental. Es equivalente conceptualmente a una tabla en bases de datos relacionales, aunque permite estructuras de datos más flexibles.

Desnormalización

Técnica de modelado de datos utilizada en bases de datos NoSQL que consiste en almacenar información redundante dentro de una misma estructura de datos con el objetivo de optimizar el rendimiento de las consultas.

Documento

Unidad básica de almacenamiento en bases de datos documentales. Generalmente se representa en formatos como JSON o BSON y puede contener estructuras de datos complejas como listas, objetos anidados y diferentes tipos de atributos.

Esquema flexible (Schema-less)

Característica de muchas bases de datos NoSQL que permite almacenar datos sin requerir una estructura rígida predefinida, facilitando la evolución del modelo de datos conforme cambian los requerimientos de la aplicación.

Modelo de agregados

Enfoque de modelado de datos utilizado en sistemas NoSQL donde los datos relacionados se agrupan dentro de una misma estructura o documento para mejorar la eficiencia de las consultas.

Modelo de datos NoSQL

Forma en que se estructuran y organizan los datos en bases de datos no relacionales, utilizando diferentes enfoques como documentos, grafos, clave-valor o columnas.

Nodo (Graph Node)

Elemento fundamental en una base de datos de grafos que representa una entidad dentro del sistema de información y puede estar conectado con otros nodos mediante relaciones.

Relación (Edge)

Conexión entre dos nodos en una base de datos de grafos que representa la relación existente dentro del modelo de datos.

Replicación de datos

Proceso mediante el cual la información almacenada en una base de datos se copia en múltiples nodos o servidores para mejorar la disponibilidad y tolerancia a fallos.

Shard (Particionamiento)

Técnica utilizada en bases de datos distribuidas que permite dividir los datos en diferentes nodos o servidores para mejorar la escalabilidad y el rendimiento del sistema.

Subdocumento

Estructura de datos anidada dentro de un documento principal en bases de datos documentales, utilizada para representar relaciones jerárquicas entre datos.
